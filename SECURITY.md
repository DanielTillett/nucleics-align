# Security policy

Nucleics Align reads sequence and scoring files, so a crash or memory error
on crafted input is treated as a security bug.

## Reporting a vulnerability

Please report it privately through GitHub's
[private vulnerability reporting](https://github.com/DanielTillett/nucleics-align/security/advisories/new)
rather than in a public issue. Include the input that triggers it, the
command or library call, and the platform.

## Supported versions

Fixes go into the latest code on the default branch.
